Hospital Management System — UML Project

Project Description

This project presents a UML Class Diagram for a Hospital Management System. The system represents the main hospital activities, including patient registration, doctor information, appointments, and medical services.

Project Objectives

* Identify the main classes in a hospital management system.
* Represent the attributes and methods of each class.
* Show the relationships between the classes using a UML Class Diagram.
* Understand how UML can be used to design a hospital management system.
